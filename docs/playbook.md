# Retention & growth playbook (research, Nov 2026)

What successful short-form creators do, adapted to Biti episodes. Numbers from industry blogs are vendor estimates — use them as direction, not truth.
Confirmed by the platforms themselves: Instagram ranks by **watch time, likes per reach, sends (DM shares) per reach**; sends weigh most for reaching non-followers. Original content is favoured, reposts/aggregation are down-ranked. TikTok weighs completion, rewatches, shares and search relevance.

## 1. The first 2 seconds decide everything
People decide to scroll in ~1.5 s. A slow opener ("Hi, I'm…", logo, calm establishing shot) is the #1 retention killer.
- **Open with the hook sentence, not the greeting.** Structure (Ziv 2026-11-06): `<surprising fact, ≤2 s>` → `<curiosity question about it, e.g. אז איך זה עובד?>` → body. No Biti greeting any more — the question keeps people watching.
- **Three layers at once, all saying the same thing:** spoken hook + big hook title on screen from frame 0 (works on mute — most feed views start muted) + motion already happening (mid-action, camera moving).
- **Number first when the topic has one** (Ziv 2026-11-07): a concrete number/shock fact in hook line 1 held best (3,000 stairs 60% vs plain question 31%). Only when a real number exists — don't force it.
- **Topics: everyday objects + broad send-group** (Ziv 2026-11-07): things people own or see daily, "שלחו את זה למי ש..." aimed at a big group.
- **Hook formulas (Hebrew)** — pick one per episode, write 2 variants:
  1. Myth-break: `<דבר> לא <עושה X> כמו שאתם חושבים.`
  2. Shock number: `הרובוט הזה נופל אלפי פעמים ביום. בכוונה.`
  3. Hidden thing: `יש דבר אחד ש<דבר מוכר> עושה, ואף אחד לא שם לב.`
  4. Direct question from everyday life: `איך השואב הרובוטי יודע שזה הסלון שלכם?`
  5. POV / "through its eyes": `ככה נראה הכביש בעיניים של מכונית בלי נהג.`
  6. Stakes: `אם החיישן הזה מפסיק לעבוד, המכונית עיוורת.`
- Avoid: vague hooks ("רובוטים זה מדהים"), questions answerable with "no", answering the hook in the first 5 seconds.

## 2. Middle: keep the loop open
- **But / therefore, never "and then".** Each sentence should create tension (אבל…) or consequence (ולכן…).
- **Re-hook at 50–60%**: a spoken pivot + visual shift — `אבל הנה החלק המטורף:` / `ופה זה נהיה מוזר.` — then the biggest wow fact. Foreshadow it once early.
- **Visual change every 2–3 seconds** (new angle, zoom, chip, counter, highlight). Never one frame for 3 s+.
- One idea per sentence, short sentences, numbers shown as on-screen counters.

## 3. Ending: payoff → loop → one ask
- Last spoken content line = **the payoff** that answers the hook, stated plainly.
- Then one short ask, ≤2 s. Viewers swipe away at sign-offs, so it must be quick.
- **Loop:** final visual echoes frame 0 (same composition) so a replay feels seamless; when possible the last line flows into the first.
- Never stack asks (follow + like + share). One ask only.

## 4. Built-in share & comment triggers
- Sends per reach is the strongest discovery signal → choose topics a viewer would **send to a specific friend** ("תראה את זה"). Ask of every idea: who would they send it to?
- Pinned comment = an opinion question that's easy to answer, e.g. `הייתם עולים למונית בלי נהג? כן / לא`, or a this-or-that. Not "what do you think?".
- Reply to early comments within the first hour (Ziv) — early engagement widens distribution.

## 5. Captions & search
- First caption line: the searchable question in plain Hebrew (e.g. `איך מכונית אוטונומית רואה את הכביש?`), then `פרק #N עם ביטי 🤖`, 2–3 lines of value, the ask, 3–5 hashtags (topic + #רובוטים #רובוטיקה #בינהמלאכותית).
- Keyword also in the on-screen hook text and spoken in the first sentence (TikTok search reads all three).
- Separate caption per platform is fine (TikTok shorter, Instagram can be longer).

## 6. Posting hygiene
- Upload the **clean exported file** to both platforms. Never download from TikTok to repost (watermark = suppressed on Instagram).
- Our music is original (generated) — good for both platforms. Don't add platform-trending sounds that are platform-specific.
- **Instagram Trial Reels**: not available on our account yet (needs a minimum follower count — Ziv 2026-11-07). Revisit when we grow.
- Consistent time (18:00 Israel) and consistent cadence (every ~2 days, same format = series recognition).
- TikTok: add every episode to a playlist "ביטי מסבירה" so episodes autoplay into each other.

## 7. Series
- Same format every episode = brand recognition (look, badge, voice, structure).
- Occasionally reference earlier episodes (`זוכרים את המכונית מפרק 1?`) → profile visits and binge.
- Expect episodes 2–3 to dip; series pick up around episode 4–5. Don't change format because of one weak episode.

## 8. What to measure (per episode, from Ziv's screenshots)
- **3-second hold** (goal >60%), **average % watched** (goal >60% for 30–45 s), **where the drop is**, sends/shares per view, follows per 1K views.
- Drop at 0–3 s → hook/first frame problem. Drop in the middle → missing re-hook / slow section. Drop at the end only → fine.
- Change one variable at a time (hook type, length, topic domain) and write the learning.
