# Hooks research (video agent, 2026-11-15, Ziv: "ההוק זה הדבר הכי חשוב")
Evidence quality: almost everything online is vendor/agency opinion. Real data found:
- OverseerOS study (Aug 2026): 4,784 hooks from 1M+-view YouTube videos (1,270 channels). 85% are NOT questions; "you" in only 33%; digits in 14%; median 11–12 spoken words (Shorts ~1 word shorter). Descriptive only, no failed-video control. Lesson: no fixed formula; study the mechanism. https://www.overseeros.com/blog/million-view-youtube-hooks-study
- Veritasium / Derek Muller PhD study: a plain clear explainer barely taught (6.0→6.3/26); opening with the viewer's misconception doubled learning (→11/26). Learning, not views. https://rosetta.to/u/veritasium/khan-academy-and-the-effectiveness-of-science-videos
- Facebook (secondhand): 65% of people who watch 3 s watch 10 s+; most mobile feed views start muted (85% FB; 54–68% other unsourced claims). https://www.kapwing.com/resources/short-form-video-statistics-tiktok-reels-and-shorts-by-the-numbers-in-2026/
- TikTok ads guidance (no data): put the hook in the first seconds — suspense, surprise or emotion; text overlays + sound. https://ads.tiktok.com/help/article/creative-best-practices?lang=en
- Our own data: "3,000 מדרגות" number hook held 60% at 3 s vs 31% for a plain question; ep008 number hook "מיליון רובוטים" only 28% (a number alone is not enough); ep012 viral "did the robot kick back?" = IG record 1,342.
Creator experience (opinion, consistent across sources):
1. Frame 0 shows the most interesting moment (Zack D. Films "How Stitches Work", 253M: the needle is at the skin before you decide to swipe). Start mid-action, at peak tension; cut any warm-up. https://danielrusnok.substack.com/p/how-a-faceless-channel-engineered · https://saturaai.com/blog/anti-hooks-youtube-shorts-opener-strategy
2. Three layers say the same thing at once: picture + on-screen text + first spoken line; must work muted. Clean frame, ~3 objects max (Jenny Hoyos). https://rosetta.to/u/vidiq/how-jenny-hoyos-actually-makes-viral-shorts
3. The first second is a contract: it states the question, the video ends when it is answered; the payoff must match the hook (Rusnok, Opus).
4. Foreshadow the payoff in the hook (Hoyos: "the most underrated thing in hooks").
5. Curiosity gap: give a hint, withhold the answer (Pope in the Pool). https://www.visualnarrative.tv/blog/the-pope-in-the-pool
6. Write several hooks and test; a couple of words can move views a lot (theclips.agency, anecdote).
