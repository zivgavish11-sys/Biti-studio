## Learnings (page-wide, from before Biti)
- Instagram does not distribute videos that already circulate on Instagram; original content (like Biti episodes) is fine on both platforms.
- Best posting time so far: 18:00 Israel. A noon test failed on both platforms.
- Hooks that worked: reverse psychology, twist ending, hot news, emotional content; everyday relevance beats dry tech.
- Biggest drop is in the first 2–3 seconds: the first frame and hook title must be strong.
- TikTok carousels perform; Instagram carousels reach mostly followers.
